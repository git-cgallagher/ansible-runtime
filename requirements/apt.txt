# Debian packages installed in the image, one per line (comments and blank lines ignored).
# Versions are NOT pinned: Debian removes old versions from its archive, so pins break builds.
# Every build runs apt-get upgrade, so the image gets Debian's security updates on top of the pinned
# base image (Dockerfile digest, bumped by Renovate). build.yml's APT_REFRESH build arg stops a cached
# layer from keeping old packages: it changes daily, and on every scheduled or manual run.

# git: ansible-galaxy installs from git sources; ansible-lint and Molecule read the repo.
git
# openssh-client: the ssh connection plugin (Linux targets, local playbook runs).
openssh-client
# sshpass: password-based ssh, for first-contact bootstrap of new hosts.
sshpass
# ca-certificates: TLS to Galaxy, PyPI, GitHub and Windows targets over HTTPS.
ca-certificates
# openssl: test certificates (isc tests/kea_dhcp/run.sh makes a throwaway CA for Kea HA TLS).
openssl
# tini: PID 1 that reaps zombies and forwards signals in `docker run`.
tini
